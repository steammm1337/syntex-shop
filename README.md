# Syntex Shop — Roblox Fishtrap

Минималистичный бело-синий магазин для Roblox Fishtrap с плавными анимациями и видео-фонами.

## Особенности

- 🎬 **Динамические видео-фоны** — два видео меняются при скролле, затем плавно переходят в статичный фон
- 🎨 **Минималистичный дизайн** — чистый бело-синий стиль без неона
- ✨ **Плавные анимации** — scroll-triggered анимации для всех элементов
- 📱 **Адаптивный дизайн** — полная поддержка мобильных устройств
- ⚡ **Оптимизация производительности** — автоматическая пауза видео при неактивной вкладке

## Структура проекта

```
syntex-shop/
├── index.html      # Основная HTML структура
├── style.css       # Все стили и адаптивность
├── script.js       # Логика видео-переключения и анимаций
└── README.md       # Документация
```

## Как использовать

1. Откройте `index.html` в браузере
2. Видео автоматически начнут воспроизводиться:
   - **Первый экран** (0-80vh): `0519(1).mp4`
   - **Второй экран** (80vh-180vh): `0519(2).mp4`
   - **После 180vh**: плавный переход к статичному фону с осьминогом и названием

## Технические детали

### Видео-система
- Видео находятся на заднем плане (`z-index: -2`)
- Полупрозрачный оверлей для читаемости текста
- Плавные переходы между видео (1s fade)
- Автоматическая пауза при скрытии вкладки

### Анимации
- Staggered animations для карточек (задержка 80-100ms)
- Parallax эффект для декоративных элементов
- Counter анимация для статистики
- Hover эффекты с bounce easing
- Ripple эффект на кнопках покупки

### Адаптивность
- Desktop: полная версия с grid layouts
- Tablet (≤1024px): адаптированные сетки
- Mobile (≤768px): мобильное меню, одноколоночные layouts
- Small mobile (≤480px): оптимизированные размеры шрифтов и отступы

## Шрифты

- **Display**: Syne (заголовки, логотип)
- **Body**: DM Sans (основной текст)

## Оптимизация

- Preload второго видео для плавного переключения
- RequestAnimationFrame для scroll handlers
- Passive event listeners
- Respect для `prefers-reduced-motion`
- Lazy loading для анимаций (Intersection Observer)

## Кастомизация

### Изменить видео
Отредактируйте пути в `index.html`:
```html
<source src="путь/к/вашему/видео1.mp4" type="video/mp4">
<source src="путь/к/вашему/видео2.mp4" type="video/mp4">
```

### Изменить точки переключения видео
В `script.js` измените значения:
```javascript
if (scrollY < windowHeight * 0.8) {        // Первое видео
if (scrollY >= windowHeight * 0.8 && scrollY < windowHeight * 1.8) {  // Второе видео
```

### Изменить цвета
В `style.css` измените CSS переменные в `:root`
